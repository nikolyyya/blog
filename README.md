# Учебный блог на Django

Учебный проект, созданный в рамках курса по Django. Простой блог с регистрацией пользователей, постами и комментариями. Проект развивался по шагам: от первой страницы на `HttpResponse` до аутентификации и привязки авторов к постам и комментариям.

**Автор:** Гринь Вероника, группа ДЭ 24-24

## Возможности

- Главная страница, список постов и страница «О проекте»
- Посты хранятся в БД (модель `Post`), в списке выводятся только опубликованные, новые сверху
- Детальная страница поста по адресу `/blog/<id>/` с обработкой несуществующих постов (404)
- Создание, редактирование и удаление постов через формы (`ModelForm`), удаление с подтверждением
- Комментарии к постам (модель `Comment`) с формой на странице поста и счётчиком
- Блок «Похожие посты» на странице поста
- Регистрация, вход и выход пользователей
- Автор поста и автор комментария привязаны к пользователю (`ForeignKey` на `User`)
- Создание, редактирование и удаление доступны только авторизованным пользователям
- Админ-панель с настроенными списками, фильтрами и поиском
- Шаблоны с наследованием (`base.html`), подключаемое меню (`include`) и собственный CSS

## Технологии

- Python 3.10+
- Django
- SQLite (по умолчанию)
- HTML, CSS

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone <ссылка-на-репозиторий>
   cd <папка-проекта>
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   # Linux / macOS / WSL
   python3 -m venv venv
   source venv/bin/activate

   # Windows
   python -m venv venv
   venv\Scripts\activate
   ```

3. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Перейдите в папку с `manage.py` и примените миграции:

   ```bash
   cd mysite
   python manage.py migrate
   ```

5. Создайте суперпользователя (для входа в админку):

   ```bash
   python manage.py createsuperuser
   ```

6. Запустите сервер разработки:

   ```bash
   python manage.py runserver
   ```

Сайт откроется по адресу <http://127.0.0.1:8000/>.

## Основные адреса

| Адрес | Что открывается |
|---|---|
| `/` | Главная страница |
| `/blog/` | Список постов |
| `/blog/<id>/` | Пост с комментариями |
| `/blog/create/` | Создание поста (для авторизованных) |
| `/blog/<id>/edit/` | Редактирование поста |
| `/blog/<id>/delete/` | Удаление поста с подтверждением |
| `/about/` | О проекте |
| `/accounts/signup/` | Регистрация |
| `/accounts/login/` | Вход |
| `/accounts/logout/` | Выход |
| `/admin/` | Админ-панель |

## Структура проекта

```
├── static/

```

## Модели

**Post**: автор (`User`), заголовок, текст, дата создания, дата изменения, флаг публикации.

**Comment**: пост (`Post`), автор (`User`), текст, дата создания. Комментарии удаляются вместе с постом.
